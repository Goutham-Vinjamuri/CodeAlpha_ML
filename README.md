## About the Repository

This repository contains three end-to-end Machine Learning and Deep Learning projects developed as part of the CodeAlpha Machine Learning Internship.

The projects demonstrate practical applications of:

* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Class Imbalance Handling (SMOTE)
* Machine Learning Algorithms
* Deep Learning using CNNs
* Model Evaluation and Comparison
* Data Visualization

---

## Projects Included

### 1. Disease Prediction

Developed a predictive model to identify the likelihood of diabetes based on patient health records.

#### Key Features

* Data Cleaning and Preprocessing
* Correlation Analysis
* Class Balancing using SMOTE
* Feature Scaling
* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* XGBoost
* Confusion Matrix Analysis
* Classification Report
* Best Model Selection

---

### 2. Credit Scoring Model

Built a credit risk assessment system capable of predicting whether a customer is likely to default on payments.

#### Key Features

* Data Preprocessing
* Missing Value Handling
* Feature Encoding
* SMOTE Oversampling
* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* XGBoost
* Credit Risk Classification
* Model Comparison and Evaluation

---

### 3. Handwritten Character Recognition

Designed a Deep Learning model to recognize handwritten English alphabet characters using Convolutional Neural Networks (CNNs).

#### Key Features

* EMNIST Letters Dataset
* Image Preprocessing
* CNN Architecture
* Model Training and Validation
* Accuracy and Loss Visualization
* Character Prediction
* Confusion Matrix
* Classification Report
* Model Saving and Deployment Ready Structure
